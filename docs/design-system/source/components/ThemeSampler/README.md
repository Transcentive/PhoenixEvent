# ThemeSampler

The same card in the three built-in themes, side by side: Sunbeam, Moonshadow and Greystone. Use it to judge a new theme against the built-in ones.

You provide: nothing. To apply a theme, set `data-theme="sunbeam"`, `data-theme="moonshadow"` or `data-theme="greystone"` on the root element or on any container.

- A theme added by a system, organization or event administrator supplies a value for every color token and passes the contrast pairs listed in the brand book before it ships.
- A theme changes color and shadow tokens. Spacing, radius and type tokens stay shared.
