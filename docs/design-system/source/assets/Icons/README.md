# Icons

Fourteen line icons on a 24px grid: 2px stroke, round caps and joins, no fill. The files are drawn in a single ink, `#2a2118` (Sunbeam `ink`). In product code, inline the same paths with `stroke="currentColor"` so the icon takes the color of its label in every theme.

| Icon | Meaning | Color role |
| --- | --- | --- |
| `organization` | Organization level | `ink` |
| `event` | Event level | `ink` |
| `station` | Station level | `ink` |
| `check-circle` | Approved, open | `positive` |
| `globe` | Public | `positive` |
| `clock` | Pending approval | `caution` |
| `hourglass` | Waiting list | `caution` |
| `ban` | Full | `critical` |
| `alert` | Error, warning before leaving the site | `critical` |
| `x-circle` | Cancelled | `neutral` |
| `eye-off` | Unlisted | `neutral` |
| `lock` | Private | `neutral` |
| `external-link` | A link that leaves the application | color of its link |
| `paperclip` | Attachment | `ink-muted` |

Every icon sits beside a text label. An icon on its own takes an `aria-label` with the same words.
